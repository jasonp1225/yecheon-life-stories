# 예천의 장면들

예천 구술 채록을 바탕으로 만든 4컷 인스타툰 62편을 모았습니다.

- [지도에서 찾기](index.html): 지역을 고르면 채록 인물과 개별 이야기 페이지로 이어집니다.
- [모든 이야기](stories.html): 인물·제목·채록명·생애 주제로 작품을 검색합니다.
- [인물 목록](people.html): 이름과 채록 지역으로 인물을 찾아봅니다.
- [선별 기준](about.html): 작품 선별 기준과 원문 인용 근거를 읽는 방법을 확인합니다.

메뉴와 지도 패널, 인물 카드에 반투명 유리 질감과 은은한 하이라이트를 적용했습니다. 만화 원본과 채록 내용은 그대로 유지했습니다.

지도 색은 마우스를 떼면 원래 색으로 돌아옵니다. 인물 이름을 누르면 별도 페이지가 열리며, 지도 돌아가기 또는 브라우저 뒤로가기로 선택했던 지역에 돌아갈 수 있습니다.

지역이 확인되지 않은 윤순옥 채록은 지도 속 지역 미확인 목록과 인물 목록에서도 볼 수 있습니다. 컴퓨터와 휴대전화에서 이용할 수 있습니다.

GitHub Pages의 게시 소스는 main 브랜치의 루트 폴더입니다.
