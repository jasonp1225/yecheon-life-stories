# 예천의 장면들

예천의 구술 채록 25건, 29명의 생애사와 일생의례를 바탕으로 만든 네 컷 만화 79편을 모았습니다.

- 지도에서 지역을 클릭해 인물을 찾고, 개인 소개와 작품을 읽을 수 있습니다.
- 모든 이야기에서 이름·제목·주제로 검색할 수 있습니다.
- 작품 상세에서 배경과 해설, 채록 원문 근거를 함께 확인할 수 있습니다.
- 작업 과정 페이지에서 원문 활용 방식과 검토 기록을 안내합니다.

현행 행정구역명인 호명읍을 사용하며, 윤순옥은 확인된 용문면에 연결했습니다. 지도 표기는 예천군 / 醴泉郡 / Yecheon-gun입니다.

이미지 속 인물과 장면은 채록을 설명하기 위한 그림이며, 말과 사건은 원문에 근거합니다. 정적 웹사이트이므로 별도의 서버 프로그램 없이 GitHub Pages에서 열 수 있습니다. 로컬에서는 이 폴더의 index.html을 여세요.
